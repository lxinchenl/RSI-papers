# RSI papers

2026 年递归自改进（RSI）论文调研与组件分类。

**[打开交互网页](https://lxinchenl.github.io/RSI-papers/)**

- 核心版 47 篇、拓展版 59 篇，共 106 个不同 arXiv ID。
- 核心：题目或摘要提到 RSI 的论文；拓展：由我们人为判断与 RSI 相关的论文。
- 按 Executor、Evaluator、Improver 及具体更新组件浏览。
- 支持模块和组件多选，默认交集，也可切换并集。
- 全库统计图使用内嵌 SVG，可单独下载；网页不依赖图片或外部绘图库。
- 模块、组件与组合图按全库合并计数，另用饼图展示核心与拓展的数量和占比，共四张图。
